          Прочтите, пожалуйста, сначала этот листок.

     Эта дискета предназначена для работы с 3  версией системы
LogoWriter. Система   состоит   из   трех  файлов  LOGOWR.COM,
LOGO.RSC и SPLASH.PIC.  Кроме этих файлов на дискете находятся
файлы PRIMARY.LWR,  TRANS.EXE, TRANS.DOC и README.TXT. Если Вы
прибрели систему LogoLitera,  то на Вашей дискете, кроме того,
имеются файлы этой системы.  Подготовка к работе и запуск сис-
темы LogoLitera описаны в справочнике по этой системе.
     Вы безусловно имеете право (и более того,  мы рекомендуем
Вам) сделать архивную копию данной дискеты.  Сделать такую ко-
пию можно с помощью команды COPY операционной системы.
     Для работы с системой LogoWriter Вам надо запустить прог-
рамму LOGOWR.COM.  Для этого,  после включения  компьютера  (и
загрузки ДОС)
     1. Вставьте данную дискету в дисковод A.
     2. Активизируйте дисковод A, выполнив команду
           A:<Enter>
     3. Запустите программу LOGOWR.COM, выполнив команду
           LOGOWR<Enter>
Дальнейшая работа описана в разделе 2.1 "Пособия для учителей".
     Если на Вашем компьютере имеется жесткий диск,  то мы со-
ветуем Вам скопировать (командой  COPY  операционной  системы)
файлы системы в какой-нибудь каталог жесткого диска.  Вы може-
те,  с помощью команды MD операционной системы, создать специ-
альный каталог для системы LogoWriter.  Если Вы, например, ре-
шили  скопировать систему в каталог LOGO жесткого диска C,  то
последовательность действий может быть следующей:
     1. Включите компьютер и загрузите ДОС.
     2. Активизируйте жесткой диск C, выполнив команду
           C:<Enter>
     3. Создайте  каталог с именем LOGO
           MD LOGO<Enter>
     4. Вставьте дискету в дисковод A.
     5. Скопируйте файлы в нужный каталог
           COPY A:LOGO*.* C:\LOGO<Enter>
           COPY A:SPLASH.PIC C:\LOGO<Enter>
Теперь для  запуска  системы  Вам достаточно перейти в каталог
LOGO
           CD LOGO<Enter>
и запустить программу LOGOWR.COM
           LOGOWR<Enter>

     Файл PRIMARY.LWR - специальный лист  LogoWriter'а, работа
с этим листом описана в разделе 2.3 "Пособия для учителей".
     Программа TRANS.EXE предназначена для  перевода  картинок
из формата PCX в формат Logo и обратно. Файл TRANS.DOC являет-
ся описанием этой программы.
     Файл README.TXT содержит текст, написанный на этом листке.
