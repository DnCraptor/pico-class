## Цель

Участник узнаёт, откуда взялся язык Си и почему на нём до сих пор написано почти всё «под капотом» компьютеров — операционные системы, прошивки, эмуляторы, в том числе тот, в котором работает его рабочее место. Участник переписывает на Си уже знакомые программы — «Угадай число», простые числа, рисунок из функций — и сравнивает Си с Паскалем; видит, что сборка программы — это два шага, компиляция и компоновка; учится читать не только ошибки, но и предупреждения компилятора.

## Результаты

После модуля участник:

- называет Денниса Ритчи и Кена Томпсона, рассказывает, зачем делали Си и что на нём написано сегодня;
- собирает и запускает программу в среде Turbo C (F9, Ctrl+F9, Alt+F5) и из командной строки (`tcc`);
- объясняет, что делает компилятор (`.C` → `.OBJ`) и компоновщик (`.OBJ` + библиотеки → `.EXE`);
- пользуется `printf`, `scanf`, `if … else`, `for`, `while`, `do … while`, фигурными скобками;
- различает `=` (присвоить) и `==` (сравнить) и понимает предупреждение `Possibly incorrect assignment`;
- пишет функцию с параметрами и вызывает её.

## План занятия

### Часть 1. Язык для операционной системы — 15 минут

1. **Unix и Си.** В 1969 году в лаборатории Bell Labs (США) **Кен Томпсон** и **Деннис Ритчи** написали операционную систему **Unix** — на ассемблере, то есть на языке команд конкретного процессора. Чтобы перенести такую систему на другой компьютер, её надо было переписать целиком. Ритчи сделал язык, на котором можно писать почти так же близко к железу, как на ассемблере, но понятный любому процессору после компиляции, — **Си** (1972; до него был язык Би). В 1973 году Unix переписали на Си, и с тех пор она переезжала с компьютера на компьютер вместе с компилятором.
2. **Книга.** В 1978 году Брайан Керниган и Деннис Ритчи выпустили книгу «Язык программирования Си». Первая программа в ней печатает `hello, world` — с тех пор её пишут первой почти на любом новом языке. В 1989 году Си стал стандартом ANSI.
3. **Turbo C.** В 1987 году Borland выпустила Turbo C — с той же средой, что у Turbo Pascal: те же меню и клавиши. Ею мы и пользуемся.
4. **Где Си сегодня.** На Си написаны ядра Linux и Windows, прошивки роутеров, телевизоров и стиральных машин, интерпретатор Python. На Си и его потомке C++ написаны и все эмуляторы нашего класса — **в том числе murm386, внутри которого сейчас работает этот Turbo C**. Си — язык, на котором компьютеры разговаривают сами с собой.
5. **Чем Си отличается от Паскаля.** Паскаль делали для обучения: он строгий и бережёт от ошибок. Си делали для системных программистов: он короткий, быстрый и доверяет программисту — разрешает работать прямо с байтами и адресами в памяти, но и ошибиться в нём легче. Компилятор Си многое пропустит, лишь предупредив.

### Часть 2. hello, world: компилятор и компоновщик — 15 минут

1. **Запуск среды.** murm386, Volkov Commander: `FREEDOS` → `EDU` → `C`. Набрать `tc hello.c`. Среда — как у Turbo Pascal.
2. **Прочитать программу.**

   ```c
   #include <stdio.h>

   int main(void)
   {
     printf("hello, world\n");
     return 0;
   }
   ```

   `#include <stdio.h>` — подключить описание функций ввода-вывода; `main` — главная функция, с неё начинается программа; `{` и `}` — как `begin` и `end`; `\n` — перевод строки; точка с запятой — после каждой команды.
3. **Ctrl+F9** — собрать и запустить, **Alt+F5** — посмотреть вывод. Выйти — **Alt+X**.
4. **То же из командной строки.** Набрать `tcc hello.c` и посмотреть, что напечатается: сначала `Turbo C` — **компилятор** перевёл текст в машинный код, файл `HELLO.OBJ`; затем `Turbo Link` — **компоновщик** (линкер) склеил этот код с готовыми функциями из библиотеки (`printf` написан не нами) и сделал `HELLO.EXE`. `dir hello.*` — три файла: текст, объектный файл, программа. `hello` — запустить.

*Вопрос:* где здесь «переводчик книги» из модуля 19? (Компилятор: переводит всю программу заранее; компоновщик собирает перевод с готовыми главами-библиотеками.)

### Часть 3. «Угадай число» на Си — 20 минут

1. **F3** → `ugadaj.c`. Сравнить с Паскалем (шпаргалка):

   ```c
   int x, g = 0, n = 0;
   randomize();
   x = random(100) + 1;
   do {
     printf("Tvoj otvet: ");
     scanf("%d", &g);
     n++;
     if (g < x)
       printf("Bolshe\n");
     else if (g > x)
       printf("Menshe\n");
   } while (g != x);
   ```

   На карте программа длиннее: она ещё проверяет, что введено число, — в Паскале на буквах программа падала с ошибкой 106, а здесь говорит «Это не число» и спрашивает снова. *Вопросы:* как в Си записан цикл «повторять, пока не угадал»? (`do … while (g != x)` — «пока не равно».) Что значит `n++`? (Прибавить к `n` единицу.) Зачем `&` перед `g` в `scanf`? (Это адрес переменной: `scanf` должен знать, *куда* положить число. Адреса — то самое «близко к железу».)
2. **Ctrl+F9** — сыграть. Ввести буквы вместо числа — что скажет программа?
3. **Опасная ошибка.** Заменить `while (g != x)` на `while (!(g = x))` — так получается, если перепутать `=` и `==`. **F9**: программа соберётся, но внизу появится `Warning: Possibly incorrect assignment` — «возможно, неверное присваивание». Запустить: игра заканчивается после первого ответа, потому что `g = x` не сравнивает, а *кладёт* загаданное число в `g`. Компилятор Си не запретил, а только предупредил. Вывод: предупреждения надо читать. Вернуть как было.
4. **Своё.** Ограничить число попыток, сделать игру до 1000. Сохранить — **F2**.

### Часть 5. Рисунок из функций — 20 минут

1. **F3** → `risunok.c`, **Ctrl+F9** — та же картинка, что в модуле 20. Любая клавиша — назад.
2. **Сравнить с Паскалем.** В Си нет отдельных «процедур» — всё функции; функция, которая ничего не возвращает, объявлена как `void`:

   ```c
   void kvadrat(int x, int y, int a, int c)
   {
     setcolor(c);
     rectangle(x, y, x + a, y + a);
   }
   ```

   Тип пишется перед именем (`int x`), а не после (`x: Integer`). Имена функций графики — маленькими буквами: Си различает `Line` и `line`.
3. **Поменять картинку и написать свою функцию** `derevo(int x, int y)`, как в модуле 20. Цвета — `RED`, `GREEN`, `YELLOW`… (шпаргалка).

## Шпаргалка (распечатать)

**Клавиши Turbo C 2.01** (как в Turbo Pascal):

| Клавиша | Что делает |
|---|---|
| **F3** / **F2** | открыть / сохранить |
| **Ctrl+F9** | собрать и запустить |
| **F9** | собрать в `.EXE` |
| **Alt+F5** | посмотреть, что программа вывела |
| **Ctrl+Break** | остановить программу |
| **F1** / **Ctrl+F1** | справка / справка о слове под курсором |
| **Alt+X** | выйти |

Из командной строки: `tcc имя.c` — собрать; с графикой — `tcc имя.c graphics.lib`; `имя` — запустить.

**Паскаль и Си:**

| Паскаль (модуль 20) | Си |
|---|---|
| `begin … end` | `{ … }` |
| `x := 5;` | `x = 5;` |
| `if x = 5 then …` | `if (x == 5) …` |
| `x <> 5` | `x != 5` |
| `and`, `or`, `not` | `&&`, `\|\|`, `!` |
| `n := n + 1;` | `n++;` |
| `WriteLn('N=', n);` | `printf("N=%d\n", n);` |
| `ReadLn(g);` | `scanf("%d", &g);` |
| `for i := 1 to 10 do` | `for (i = 1; i <= 10; i++)` |
| `repeat … until g = x;` | `do { … } while (g != x);` |
| `while d * d <= n do` | `while (d * d <= n)` |
| `Random(100) + 1` | `random(100) + 1` |
| `var x: Integer;` | `int x;` |
| `procedure P(a: Integer);` | `void p(int a)` |
| `{ комментарий }` | `/* комментарий */` |

**`printf`:** `%d` — целое, `%f` — дробное (`%.2f` — два знака после точки), `%s` — строка, `\n` — новая строка.

**Графика (`#include <graphics.h>`):** `setcolor(c)`; `line(x1, y1, x2, y2)`; `rectangle(x1, y1, x2, y2)`; `circle(x, y, r)`; `setfillstyle(SOLID_FILL, c)` и `bar(x1, y1, x2, y2)`; `fillellipse(x, y, rx, ry)`; `outtextxy(x, y, "text")`. Цвета: `BLACK`, `BLUE`, `GREEN`, `CYAN`, `RED`, `MAGENTA`, `BROWN`, `LIGHTGRAY`, `DARKGRAY`, `LIGHTBLUE`, `LIGHTGREEN`, `LIGHTCYAN`, `LIGHTRED`, `LIGHTMAGENTA`, `YELLOW`, `WHITE`.
