# Исходники программы SOUNDS для murm386 (звуковые устройства PC)

Программа на Turbo Pascal 5.5 с карты `sdcard/freedos/EDU/SOUNDS`. Написана для этого репозитория и распространяется на условиях [`LICENSE`](../../LICENSE). Она играет одну и ту же мелодию («Ода к радости», 8 тактов, с басом) на всех звуковых устройствах, которые эмулирует murm386, — чтобы на занятии ([учебный модуль 15](../../program/modules/15-pc-sound.md)) услышать разницу, ничего не программируя.

| Файл | Что это |
|---|---|
| [`SOUNDS.PAS`](../../sdcard/freedos/EDU/SOUNDS/SOUNDS.PAS) | исходник, концы строк CRLF; открывается в `TURBO.EXE` прямо на рабочем месте |
| [`SOUNDS.EXE`](../../sdcard/freedos/EDU/SOUNDS/SOUNDS.EXE) | собранная программа |
| [`SPEECH.RAW`](../../sdcard/freedos/EDU/SOUNDS/SPEECH.RAW) | фраза «Привет! Это цифровой звук.»: 8000 отсчётов в секунду, 8 бит без знака, моно — то, что принимает ЦАП |
| `build.sh` | сборка на ПК в DOSBox-X |
| `mkspeech.sh` | изготовление `SPEECH.RAW` |

Меню программы (клавиша — устройство):

| Клавиша | Устройство | Как играет |
|---|---|---|
| **1** | PC speaker | таймер 8254, канал 2, и порт 61h: один прямоугольный голос — только мелодия, без баса |
| **2** | Tandy / PCjr | PSG SN76489, порт C0h: мелодия и бас — два прямоугольных голоса |
| **3** | AdLib | OPL2 (YM3812), порты 388h/389h: FM-синтез, мелодия и бас на двух из девяти голосов |
| **4** | Covox Sound Master | PSG AY-3-8930, порты 240h/241h: два прямоугольных голоса |
| **5** | Roland MPU-401 | порты 330h/331h, режим UART: только ноты MIDI — «пианино» (программа 0) и «бас» (программа 32), звук делает синтезатор |
| **6** | Covox Speech Thing | ЦАП на LPT2 (порт 278h): программа считает волну и сама выдаёт 8000 чисел в секунду по таймеру, потом — речь из `SPEECH.RAW` |
| **7** | Disney Sound Source | ЦАП с буфером на 16 чисел на LPT1 (порты 378h–37Ah): берёт числа со своей скоростью 7000 в секунду, программа только подкладывает их, когда буфер не полон; потом — та же речь |
| **8** | Sound Blaster | ЦАП, порт 220h, IRQ 5, DMA 1: волну передаёт контроллер DMA (команда DSP 14h, 8000 Гц), процессор свободен; потом — та же речь |
| **A** | AdLib | четыре FM-инструмента одной гаммой: флейта, пианино, труба, колокольчик — меняются только числа в регистрах OPL2 |

Запускать из каталога `\FREEDOS\EDU\SOUNDS`: `SPEECH.RAW` читается из текущего каталога (без него речи не будет, мелодия сыграет). **Esc** — остановить звук или выйти. `SOUNDS 3` — сыграть устройство 3 и выйти (для показа с доски одной командой). Для пунктов 6–8 волна сначала вычисляется (синус с затуханием плюс прямоугольный бас) — на murm386 без PSRAM это занимает несколько секунд, на экране написано «computing the wave...».

Устройство сначала включается в настройках murm386 (**Win+F11**), иначе программа ничего не услышит или напишет, что устройства нет. Какие строки менять — [`SDCARD.md`](../../SDCARD.md), раздел 4, строка `/freedos/EDU/SOUNDS`.

## Сборка

На рабочем месте — в Volkov Commander зайти в `\FREEDOS\EDU\SOUNDS` и набрать `tpc sounds`: Turbo Pascal 5.5 лежит в `\FREEDOS\EDU\TP55`, каталог включён в `PATH`. Править исходник удобно в `TURBO.EXE`, но собирать — `tpc`: среда по умолчанию компилирует в память, а не в файл.

На ПК с Linux — `./build.sh`: запускает тот же `TPC.EXE` с карты в DOSBox-X без окна и печатает его отчёт. Нужен пакет `dosbox-x` (проверено с 2024.03.01). Сборка повторяемая: тот же исходник даёт побайтово тот же `SOUNDS.EXE`.

`SPEECH.RAW` делает `./mkspeech.sh` — синтезатор речи eSpeak NG (1.51) и SoX (14.4), пакеты `espeak-ng` и `sox`. Результат тоже повторяемый (у SoX выключено подмешивание шума, ключ `-D`).

Ограничения Turbo Pascal 5.5, которые пришлось учесть: нет `Break` и `Continue`, нет директивы `far` (вместо неё `{$F+}`), модуль `Crt` не используется — его `Delay` на быстрых машинах ломается. Все паузы считаются по таймеру 8254 (канал 0, режим 2), в конце режим таймера возвращается.

## Проверка

Пункты 1, 2, 3, 6, 7, 8 и A проверены в DOSBox-X (Sound Blaster 16, `oplmode=opl2`, `tandy=on`, `disney=true`, Covox на LPT2 — `parallel2=disney`): звук записан в файл, высота каждой ноты сверена с частотным анализом, четыре инструмента AdLib различаются по спектру. В DOSBox-X нет Covox Sound Master и встроенного синтезатора MIDI, поэтому пункты 4 и 5 проверены только по исходникам murm386 (`csm.c`, `mpu401.c.inl`) — на рабочем месте послушать их перед занятием.
