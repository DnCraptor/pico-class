# Исходники программ для pico-lynx (Atari Lynx)

Программы на C с карты `sdcard/LYNX/*.lnx`. Написаны для этого репозитория и распространяются на условиях [`LICENSE`](../../LICENSE). Это те же три программы, что для PC Engine, Mega Drive и Game Boy в [`tools/pce`](../pce/README.md), [`tools/md`](../md/README.md) и [`tools/gb`](../gb/README.md), с теми же рисунками спрайтов.

| Файл | Картридж | Что показывает |
|---|---|---|
| `hello.c` | [`hello.lnx`](../../sdcard/LYNX/hello.lnx) | текст на экране (`tgi_outtextxy`), цвета, часы (`clock`), нажатые кнопки (`joy_read`), звук; экран каждый кадр рисуется заново и показывается целиком (`tgi_updatedisplay`) |
| `sprite.c` | [`sprite.lnx`](../../sdcard/LYNX/sprite.lnx) | спрайты Suzy (`tgi_sprite`): робот на крестовине, мяч летает сам и отскакивает от краёв, касание считается; A меняет палитру перьев робота, B увеличивает его в 2 и 3 раза — растягивает сам видеочип |
| `catch.c` | [`catch.lnx`](../../sdcard/LYNX/catch.lnx) | законченная игра «Лови звёзды»: корзина внизу, три звезды падают всё быстрее, три промаха — конец игры, лучший счёт запоминается |
| `beep.h` | — | звук: канал A звукового чипа Mikey — таймер, который сдвигает регистр с обратной связью; с одним отводом получается прямоугольная волна |
| `mksprites.py` | — | спрайты нарисованы в нём текстом (цифра — номер «пера») и превращаются в данные спрайтов Suzy `sprite_gfx.h`, `catch_gfx.h`; какой цвет у каждого пера, задаёт палитра перьев в блоке управления спрайтом (`SCB_REHV_PAL`) |

Чем отличаются от версий для других приставок: экран 160×102 точки и 16 цветов из 4096; спрайты не стоят в таблице, как у PC Engine, Mega Drive и Game Boy, а рисуются видеочипом Suzy прямо в память экрана — зато любого размера и с растяжением. Клавиши pico-lynx — в [`../../SDCARD.md`](../../SDCARD.md), раздел 17.

## Сборка

Компилятор — [cc65](https://cc65.github.io) (zlib; пакет `cc65` в Debian/Ubuntu, проверено на 2.19), библиотеки графики, джойстика и картриджа Lynx входят в него. Из этого каталога:

```sh
./build.sh
```

`build.sh` запускает `mksprites.py`, компилирует три программы (`cl65 -t lynx`) и кладёт картриджи в `../../sdcard/LYNX`. Сборка повторяемая: те же исходники дают побайтово те же файлы. Расширение — строчными буквами: pico-lynx показывает в списке только `*.lnx`, `*.com` и `*.o`.

Картриджи проверены на ядре Handy из [DnCraptor/pico-lynx](https://github.com/DnCraptor/pico-lynx) (`bf9f9fe`), собранном для ПК: экран, отклик на кнопки, звук, растяжение спрайта, счёт в `sprite.lnx` и `catch.lnx` (для проверки корзину водила программа).
