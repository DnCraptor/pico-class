# Исходники программ для pico-gameboy (Nintendo Game Boy)

Программы на C с карты `sdcard/GB/*.gb`. Написаны для этого репозитория и распространяются на условиях [`LICENSE`](../../LICENSE). Это те же три программы, что для PC Engine и Mega Drive в [`tools/pce`](../pce/README.md) и [`tools/md`](../md/README.md), и для Atari Lynx в [`tools/lynx`](../lynx/README.md), с теми же рисунками спрайтов. Картриджи по 32 КБ, без маппера.

| Файл | Картридж | Что показывает |
|---|---|---|
| `hello.c` | [`hello.gb`](../../sdcard/GB/hello.gb) | текст на экране (`printf`, `gotoxy`), четыре оттенка экрана (регистр палитры `BGP_REG`), часы на счётчике кадров (`vsync`), нажатые кнопки (`joypad`), звук |
| `sprite.c` | [`sprite.gb`](../../sdcard/GB/sprite.gb) | аппаратные спрайты 8×16 (`set_sprite_data`, `move_sprite`): робот на крестовине, мяч летает сам и отскакивает от краёв, касание считается; кнопка A переключает робота на вторую палитру спрайтов |
| `catch.c` | [`catch.gb`](../../sdcard/GB/catch.gb) | законченная игра «Лови звёзды»: корзина внизу, три звезды падают всё быстрее, три промаха — конец игры, лучший счёт запоминается |
| `beep.h` | — | звук: прямоугольная волна на канале 1 со спадающей громкостью, регистры `NR10`–`NR52` |
| `mksprites.py` | — | спрайты нарисованы в нём текстом и превращаются в тайлы 8×8 по 2 бита на точку `sprite_gfx.h`, `catch_gfx.h`; у Game Boy всего четыре оттенка, поэтому для каждого спрайта задано, какой цифре рисунка какой оттенок соответствует |

Чем отличаются от версий для PC Engine и Mega Drive: экран 160×144 точек и всего четыре оттенка (у оригинального Game Boy — зеленоватые), спрайт 16×16 — это два аппаратных спрайта 8×16, текст выводится обычным `printf`. Клавиши pico-gameboy — в [`../../SDCARD.md`](../../SDCARD.md), раздел 16.

## Сборка

Компилятор — [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020) (проверено на 4.5.0, архив `gbdk-linux64.tar.gz` — распаковать). Из этого каталога:

```sh
GBDK=/путь/к/gbdk ./build.sh
```

`build.sh` запускает `mksprites.py`, компилирует три программы (`lcc`, название игры в заголовке картриджа — ключ `-Wm-yn`) и кладёт картриджи в `../../sdcard/GB`. Сборка повторяемая: те же исходники дают побайтово те же файлы. Расширение — строчными буквами: pico-gameboy показывает в списке только файлы `*.gb` и `*.gbc`.

Картриджи проверены на ядре Peanut-GB из [DnCraptor/pico-gameboy](https://github.com/DnCraptor/pico-gameboy) (`b48d419`), собранном для ПК: экран, отклик на кнопки, звук, счёт в `sprite.gb` и `catch.gb` (для проверки корзину водила программа).
