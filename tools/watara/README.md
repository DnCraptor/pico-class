# Исходники программ для pico-watara (Watara Supervision)

Программы на C с карты `sdcard/WATARA/*.sv`. Написаны для этого репозитория и распространяются на условиях [`LICENSE`](../../LICENSE), кроме шрифта `font_gfx.h` (см. ниже). Это те же три программы, что для PC Engine, Mega Drive, Game Boy, Lynx и Gamate в [`tools/pce`](../pce/README.md), [`tools/md`](../md/README.md), [`tools/gb`](../gb/README.md), [`tools/lynx`](../lynx/README.md) и [`tools/gamate`](../gamate/README.md), с теми же рисунками спрайтов.

| Файл | Картридж | Что показывает |
|---|---|---|
| `hello.c` | [`hello.sv`](../../sdcard/WATARA/hello.sv) | текст на экране, четыре оттенка, часы (кадры от прерывания NMI, которое приходит раз в кадр), нажатые кнопки (`joy_read`), звук; текст перерисовывается, только когда что-то изменилось |
| `sprite.c` | [`sprite.sv`](../../sdcard/WATARA/sprite.sv) | «спрайты» без спрайтов: робот на крестовине, мяч летает сам и отскакивает от краёв, касание считается; A меняет оттенки робота, B делает его вдвое больше. Программа сама стирает картинку на старом месте и копирует на новое |
| `catch.c` | [`catch.sv`](../../sdcard/WATARA/catch.sv) | законченная игра «Лови звёзды»: корзина внизу, три звезды падают всё быстрее, три промаха — конец игры, лучший счёт запоминается |
| `sv.h` | — | экран, текст, перенос картинок и звук: всё, что у других приставок делает видеочип, здесь делает программа |
| `mkgfx.py` | — | спрайты нарисованы в нём текстом (цифра — номер «пера»), каждому перу дан один из четырёх оттенков; скрипт пишет `sprite_gfx.h` и `catch_gfx.h` |
| `font_gfx.h` | — | шрифт 8×8, символы 32–95: взят из библиотеки cc65 для Gamate (`libsrc/gamate/vga.inc`), лицензия zlib — её текст в начале файла |

Чем отличаются от версий для других приставок: экран 160×160 точек и 4 оттенка; у Supervision нет ни спрайтов, ни знакогенератора — только память экрана (48 байт на строку, 4 точки в байте, 2 бита на точку, левая точка в младших битах). Поэтому каждая картинка хранится четыре раза, уже сдвинутой на 0–3 точки, а при движении стирается только та часть старого места, которую не закроет новая картинка, — иначе она мерцала бы. Робот увеличивается только вдвое: большой робот — отдельная картинка. Звук: два канала прямоугольной волны, частота 4 МГц / 32 / (период + 1). Клавиши pico-watara — в [`../../SDCARD.md`](../../SDCARD.md), раздел 20.

## Сборка

Компилятор — [cc65](https://cc65.github.io) (zlib; пакет `cc65` в Debian/Ubuntu, проверено на 2.19), библиотеки джойстика и картриджа Supervision входят в него. Из этого каталога:

```sh
./build.sh
```

`build.sh` запускает `mkgfx.py`, компилирует три программы (`cl65 -t supervision`) и кладёт картриджи в `../../sdcard/WATARA`. Сборка повторяемая: те же исходники дают побайтово те же файлы.

Картриджи проверены в эмуляторе MAME 0.264 (машина `svision`): экран, отклик на кнопки (кнопки нажимал скрипт), счёт, частота звука по записи (`-wavwrite`). На pico-watara — при приёмке комплекта.
