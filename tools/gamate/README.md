# Исходники программ для pico-gamate (Gamate)

Программы на C с карты `sdcard/GAMATE/*.bin`. Написаны для этого репозитория и распространяются на условиях [`LICENSE`](../../LICENSE), кроме шрифта `font_gfx.h` (см. ниже). Это те же три программы, что для PC Engine, Mega Drive, Game Boy, Lynx и Watara Supervision в [`tools/pce`](../pce/README.md), [`tools/md`](../md/README.md), [`tools/gb`](../gb/README.md), [`tools/lynx`](../lynx/README.md) и [`tools/watara`](../watara/README.md), с теми же рисунками спрайтов; исходники `hello.c`, `sprite.c`, `catch.c` почти те же, что для Supervision, — отличается файл `gm.h`.

| Файл | Картридж | Что показывает |
|---|---|---|
| `hello.c` | [`hello.bin`](../../sdcard/GAMATE/hello.bin) | текст на экране, четыре оттенка, часы, нажатые кнопки (`joy_read`), звук |
| `sprite.c` | [`sprite.bin`](../../sdcard/GAMATE/sprite.bin) | «спрайты» без спрайтов: робот на крестовине, мяч летает сам и отскакивает от краёв, касание считается; A меняет оттенки робота, B делает его вдвое больше |
| `catch.c` | [`catch.bin`](../../sdcard/GAMATE/catch.bin) | законченная игра «Лови звёзды»: корзина внизу, три звезды падают всё быстрее, три промаха — конец игры, лучший счёт запоминается |
| `gm.h` | — | экран, текст, перенос картинок и звук |
| `mkgfx.py` | — | спрайты нарисованы в нём текстом, каждому перу дан один из четырёх оттенков; скрипт пишет `sprite_gfx.h` и `catch_gfx.h` |
| `fixcart.py` | — | вписывает в заголовок картриджа контрольную сумму: BIOS Gamate складывает байты 7000–7FFF и без верной суммы картридж не запускает (то же делает `util/gamate/gamate-fixcart.c` из cc65) |
| `font_gfx.h` | — | шрифт 8×8, символы 32–95, из библиотеки cc65 для Gamate (`libsrc/gamate/vga.inc`), лицензия zlib — её текст в начале файла |

Чем отличаются от версий для других приставок: экран 160×152 точки и 4 оттенка, спрайтов и знакогенератора нет. Память экрана — две битовые плоскости по 8 точек в байте, и процессор не видит её напрямую: программа сообщает видеочипу столбец (`LCD_X`) и строку (`LCD_Y`) и пишет байты в `LCD_DATA`, а видеочип сам переходит на строку ниже. Поэтому картинки хранятся по столбцам, восемь раз — сдвинутыми на 0–7 точек. Кадр — два прерывания таймера BIOS (их около 128 в секунду). Звук — микросхема вроде AY-3-8910 (как в ZX Spectrum 128), канал C идёт в оба динамика. Клавиши pico-gamate — в [`../../SDCARD.md`](../../SDCARD.md), раздел 19.

## Сборка

Компилятор — [cc65](https://cc65.github.io) (zlib; пакет `cc65` в Debian/Ubuntu, проверено на 2.19), библиотеки джойстика и картриджа Gamate входят в него. Из этого каталога:

```sh
./build.sh
```

`build.sh` запускает `mkgfx.py`, компилирует три программы (`cl65 -t gamate`), вписывает контрольную сумму (`fixcart.py`) и кладёт картриджи в `../../sdcard/GAMATE`. Сборка повторяемая: те же исходники дают побайтово те же файлы.

Картриджи проверены в эмуляторе MAME 0.264 (машина `gamate`, BIOS — тот же, что встроен в pico-gamate): экран, отклик на кнопки (кнопки нажимал скрипт), частота звука по записи (`-wavwrite`). На pico-gamate — при приёмке комплекта.
