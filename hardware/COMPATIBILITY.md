# Матрица совместимости прошивок и плат

Статус на 2026-10-16. Таблица фиксирует **результаты проверки**, а не заявления авторов прошивок. Строка меняет статус только после приёмки по процедуре из раздела 5 инструкции соответствующей платы (для Olimex — [`olimex-pico-pc/README.md`](olimex-pico-pc/README.md)).

Обозначения статуса: ✅ принято, ⚠️ работает с оговорками (см. примечание), ❌ не работает, ⬜ не проверялось.

Коды плат совпадают с префиксами сборок MOS2 и расширениями, по которым MOS2 распознаёт прошивки своей платы:

| Код | Плата |
|---|---|
| `PCp2` | Olimex RP2040-PICO-PC + Raspberry Pi Pico 2 — **основная** |
| `m1p2` | Murmulator 1.x + модуль на RP2350; звук — PWM или ЦАП TDA1387 (I2S) на GP26–GP28, в зависимости от варианта сборки; инструкция — [`murmulator1x/README.md`](murmulator1x/README.md) |
| `m2p2` | Murmulator 2.0 + Raspberry Pi Pico 2 (RP2350A); звук — свой (ЦАП TDA1387 или PWM на гнезде платы); инструкция — [`murmulator20/README.md`](murmulator20/README.md) |
| `z0p2` | Waveshare RP2350-PiZero — требует дополнительного звукового модуля; инструкция — [`waveshare-rp2350-pizero/README.md`](waveshare-rp2350-pizero/README.md) |

## 3. Правила ведения

- Одна строка — одна конкретная сборка (файл) на одной плате.
- «Звук через HDMI» заполняется обязательно: прошивки, выводящие звук в HDMI, зазвучат из динамиков монитора (см. п. 1.7.4 программы).
- «Частота / напряжение» — с какими частотой и напряжением ядра работает прошивка. Модуль Pico 2 на рабочем месте должен устойчиво держать эти значения.
- «Доп. оборудование» — что нужно сверх минимальной конфигурации (PSRAM, мышь, NES DPAD и т. п.); прочерк, если ничего. Прошивка с дополнительными требованиями используется в опциональных модулях.
- Таблица отражает текущее состояние: в ней только прошивки, которые есть в репозитории. При смене версии строка обновляется, при удалении прошивки — удаляется; история изменений — в истории репозитория.
