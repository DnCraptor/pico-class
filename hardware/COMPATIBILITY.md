# Матрица совместимости прошивок и плат

Статус на 2026-10-01. Таблица фиксирует **результаты проверки**, а не заявления авторов прошивок. Строка меняет статус только после приёмки по процедуре из раздела 5 инструкции соответствующей платы (для Olimex — [`olimex-pico-pc/README.md`](olimex-pico-pc/README.md)).

Обозначения статуса: ✅ принято, ⚠️ работает с оговорками (см. примечание), ❌ не работает, ⬜ не проверялось.

Коды плат совпадают с префиксами сборок MOS2 и расширениями, по которым MOS2 распознаёт прошивки своей платы:

| Код | Плата |

| `m1p2` | Murmulator 1.x с RP2350 |
| `m2p2` | Murmulator 2.0 (RP2350B) |
| `z0p2` | Waveshare RP2350-PiZero |

## 3. Правила ведения

- Одна строка — одна конкретная сборка (файл) на одной плате.
- «Звук через HDMI» заполняется обязательно: прошивки, выводящие звук в HDMI, зазвучат из динамиков монитора (см. п. 1.7.4 программы).
- «Частота / напряжение» — с какими частотой и напряжением ядра работает прошивка. Модуль Pico 2 на рабочем месте должен устойчиво держать эти значения.
- «Доп. оборудование» — что нужно сверх минимальной конфигурации (PSRAM, мышь, NES DPAD и т. п.); прочерк, если ничего. Прошивка с дополнительными требованиями используется в опциональных модулях.
- При смене версии прошивки старая строка не удаляется, а получает статус ❌ или пометку «заменено» — так видна история.
