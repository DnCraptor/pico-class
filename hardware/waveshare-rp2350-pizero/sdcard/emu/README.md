# Эмуляторы для Waveshare RP2350-PiZero

Здесь будут прошивки эмуляторов, собранные для платы `z0p2`, с той же раскладкой, что у Olimex (`hardware/olimex-pico-pc/sdcard/emu/`), включая подкаталог `psram/` для сборок с PSRAM. Содержимое каталога `sdcard/` копируется поверх общего `sdcard/` в корень SD-карты. Состав — в [`../../MANIFEST.md`](../../MANIFEST.md). Этот файл-заглушка удаляется, когда появятся первые прошивки.
