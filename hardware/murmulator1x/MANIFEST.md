# Манифест комплекта: Murmulator 1.x с RP2350 (m1p2)

Состояние на 2026-10-16: есть pico-launcher, MOS2, murm386, PICO-BK, pico-nes, murmapple (Apple IIe), pico-z26 (Atari 2600), atari800, pico-speccy (ZX Spectrum), murmulator_game_n_watch (Game & Watch), murmc64 (Commodore 64), frank-micro (BBC Micro), frank-msx (MSX), emu80v4 («Вектор-06Ц», «Корвет»), pico-pce (PC Engine), pico-genesisPlus (Mega Drive), pico-gameboy (Game Boy), pico-lynx (Atari Lynx), pico-mac (Macintosh 128K), pico-gamate (Gamate), pico-watara (Watara Supervision) и pico-wonderswan (WonderSwan). Файл фиксирует, **что именно** лежит в каталоге платы, из каких исходников оно собрано и как проверить целостность — по образцу [`../olimex-pico-pc/MANIFEST.md`](../olimex-pico-pc/MANIFEST.md). При добавлении или замене любого файла обновляются эта таблица, `SHA256SUMS` и статус в [`../COMPATIBILITY.md`](../COMPATIBILITY.md).

Прошивки каталога собраны 2026-10-16 с профилем платы Murmulator 1.x, с тех же коммитов, что и для m2p2 (и PCp2): pico-launcher — `5d871d7`, MOS2 — `a77484c`, murm386 — `fc80323`, PICO-BK — `2704872`, pico-nes — `3bfd622`, murmapple — `d3b263d`, pico-z26 — `68b7a25`, atari800 — `d72f2c4`, murmulator_game_n_watch — `4bd3f4d`, murmc64 — `8440245`, frank-micro — `4b50892`, frank-msx — `eefe07a`, emu80v4 «Вектор-06Ц» — `f55ad6b`, «Корвет» — `730ea0f`, pico-pce — `f626c4a`, pico-genesisPlus — `e0a7d35` (I2S) и `8b21c3c` (PWM), `pico_shared` `019891a`; pico-gameboy — `146adc4`, pico-lynx — `82b2da8`, pico-mac — `2d96eb1`; pico-gamate и pico-watara — готовые сборки из релизов v.3.1.2 (`fae8b33`) и v.2.2.1 (`9d8cd79`); pico-wonderswan — готовые сборки из релиза v.1.0.6 (`4665d2d`); pico-speccy — готовые сборки из релиза v1.0.10 (`b093a8f`). Образы — для RP2350 в режиме ARM Secure (UF2 family `0xe48bff59`). Параметры сборки восстановлены по именам файлов.

Выводы Murmulator 1.x, общие для этих прошивок (по профилю `BOARD_M1` в `src/board_config.h` murm386 и профилю M1 в `CMakeLists.txt` MOS2): HDMI и VGA — GP6–GP13, SD-карта — SCK 2, MOSI 3, MISO 4, CS 5, клавиатура PS/2 — GP0 (CLK) / GP1 (DATA), геймпад NES — CLK 14, LAT 15, DATA 16, звук PWM — GP26 / GP27 (бипер GP28), I2S у murm386 — DATA 26, BCK 27, LRCK 28.

## 2. Платформенная часть SD-карты (`sdcard/`)

Карту готовят как для Olimex: сначала общий `sdcard/` из корня репозитория, затем поверх — `sdcard/` этой платы.

| Путь на карте | Происхождение | Отличия от источника |
|---|---|---|
| `/emu/*.uf2`, `/emu/psram/*.uf2` | см. раздел 1, «Эмуляторы» | побайтово совпадают с файлами сборки |
| `/mos2/README.md` | памятка по MOS2 для m1p2, написана для этого репозитория | кодировка CP866, концы строк LF — читается прямо в MOS2 (`type`, `mcview`) |

## 3. Проверка целостности

Из каталога `hardware/murmulator1x`:

```sh
sha256sum -c SHA256SUMS          # Linux, Git Bash в Windows
shasum -a 256 -c SHA256SUMS      # macOS
```

Здесь проверяются только файлы платы; общая часть карты — по `SHA256SUMS` в корне репозитория (см. `SDCARD.md`, раздел 23).
