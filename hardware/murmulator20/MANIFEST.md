# Манифест комплекта: Murmulator 2.0 + Raspberry Pi Pico 2 (m2p2)

Состояние на 2026-10-20: есть pico-launcher, MOS2, murm386, PICO-BK, NES, murmapple (Apple IIe), pico-z26 (Atari 2600), atari800, pico-speccy, Game & Watch, murmc64 (Commodore 64), frank-micro (BBC Micro), frank-msx (MSX), emu80v4 («Корвет», «Вектор-06Ц»), pico-pce (PC Engine), pico-genesisPlus (Mega Drive), pico-gameboy (Game Boy), pico-lynx (Atari Lynx), pico-mac (Macintosh 128K), pico-gamate (Gamate), pico-watara (Watara Supervision), pico-wonderswan (WonderSwan) и pico-neogeo-pocket (Neo Geo Pocket), а также схема и гербер-файлы платы. Файл фиксирует, **что именно** лежит в каталоге платы, из каких исходников оно собрано и как проверить целостность — по образцу [`../olimex-pico-pc/MANIFEST.md`](../olimex-pico-pc/MANIFEST.md). При добавлении или замене любого файла обновляются эта таблица, `SHA256SUMS` и статус в [`../COMPATIBILITY.md`](../COMPATIBILITY.md).

Прошивки каталога собраны 2026-10-14 с профилем платы Murmulator 2; pico-launcher, MOS2, murm386 и PICO-BK — с тех же коммитов, что и для PCp2; NES — из `main` pico-nes (`2eb90d9`, пересобран 2026-10-20), murmapple и pico-z26 — из `main` (`d3b263d` и `68b7a25`), тех же коммитов, что для z0p2; atari800 — из `master` = `d72f2c4`, сборки z0p2 плюс профиль m2p2 и исправление вывода I2S; pico-speccy — готовые сборки из релиза v1.0.9; Game & Watch и murmc64 — из `4bd3f4d` и `8440245`, тех же коммитов, что для z0p2; frank-micro — из `main` = `4b50892`, сборки z0p2 плюс настройка CMake для m2p2; frank-msx — из `main` = `9b8e9e4`, того же коммита, что для z0p2; emu80v4 — из веток `korvet` = `730ea0f` и `vector06c` = `f55ad6b`, тех же коммитов, что для PCp2 и z0p2; pico-pce — из `main` = `f626c4a`, сборки z0p2 плюс исправления для m2p2; pico-genesisPlus — из `main` = `a13b2b0` с `pico_shared` = `09e14c7`; pico-gameboy и pico-lynx — из `main` (`146adc4` и `82b2da8`), сборки z0p2 плюс исправления для m2p2 (раздел 1, «Эмуляторы»); pico-mac — из `main` = `6cbc144`, сборки z0p2 плюс исправления для m2p2; pico-gamate, pico-watara и pico-wonderswan — готовые сборки из релизов v.3.1.2 (`fae8b33`), v.2.2.1 (`9d8cd79`) и v.1.0.6 (`4665d2d`); pico-neogeo-pocket — из `main` = `f90a1a2`, сборки z0p2 плюс профиль m2p2 и исправление вывода I2S; образы — для RP2350 в режиме ARM Secure (UF2 family `0xe48bff59`). Параметры сборки восстановлены по именам файлов.

## 3. Платформенная часть SD-карты (`sdcard/`)

Карту готовят как для Olimex: сначала общий `sdcard/` из корня репозитория, затем поверх — `sdcard/` этой платы.

| Путь на карте | Происхождение | Отличия от источника |
|---|---|---|
| `/emu/*.uf2`, `/emu/psram/*.uf2` | см. раздел 1, «Эмуляторы» | побайтово совпадают с файлами сборки |
| `/mos2/README.md` | памятка по MOS2 для m2p2, написана для этого репозитория | кодировка CP866, концы строк LF — читается прямо в MOS2 (`type`, `mcview`) |

## 4. Проверка целостности

Из каталога `hardware/murmulator20`:

```sh
sha256sum -c SHA256SUMS          # Linux, Git Bash в Windows
shasum -a 256 -c SHA256SUMS      # macOS
```

Здесь проверяются только файлы платы; общая часть карты — по `SHA256SUMS` в корне репозитория (см. `SDCARD.md`, раздел 23).
