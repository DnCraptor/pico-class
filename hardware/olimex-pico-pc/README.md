# Подготовка рабочего места: Olimex RP2040-PICO-PC + Raspberry Pi Pico 2

Статус: рабочая инструкция, редакция 0.1 (2026-09-30). Минимальная конфигурация: на ней выполняются все базовые модули программы.

## 1. Комплектация одного рабочего места

| Компонент | Количество | Примечание |
|---|---:|---|
| Olimex RP2040-PICO-PC | 1 | Основная плата |
| Raspberry Pi Pico 2 | 1 | или полностью электрически совместимый клон на МК RP2350, с припаянными штыревыми контактами, например: WeAct / Waveshare RP2350-Plus, Pimoroni Pico 2 Plus  |
| Монитор HDMI | 1 | С совместимым видеорежимом (обязательна поддержка 640*480 60 Гц), HDMI входом и HDMI-HDMI кабелем; для эмулятора БК (PICO-BK) по умолчанию нужен режим 720×576 при 50 Гц (CEA 576p), при отборе модулей Pico 2 (раздел 5.3) — также 800×600 и 1024×768 при 60 Гц; однорежимные кассовые мониторы, не поддерживающие 640×480 при 60 Гц, не подходят |
| USB-клавиатура HID, 101+ клавиша | 1 | Полноразмерная, с NumPad |
| microSD-карта | 1 | Форматирование FAT32; требуется проверка совместимости с протоколом SPI (чаще всего это карты объёмом до 32 GB) |
| Наушники | 1 | Для учащегося; на местах преподавателя и демонстрации — активные колонки |
| Кабели и питание | комплект | Блок питания 5 В с кабелем micro-USB для разъёма питания платы Olimex (желательно предварительное тестирование, чтобы избежать проблем с уровнем пульсаций). USB-клавиатура подключается к разъёму micro-USB модуля Pico 2 через OTG-переходник USB-A (гнездо) → micro-USB (штекер); подбор переходника требует тестирования с конкретным экземпляром, в некоторых случаях может потребоваться USB OTG HUB с отдельным питанием |

Внешняя PSRAM, USB-мышь и NES DPAD — опции, не необходимые для базового рабочего места.

## 2. Аппаратная подготовка

1. Осмотреть платы, разъёмы и отсутствие механических повреждений. Модуль Pico 2 перед установкой на место учащегося проходит отбор по разделу 5.3.
2. При отключённом питании установить Pico 2 в разъёмы платы расширения, соблюдая ориентацию согласно маркировке Olimex. Не пытаться вставлять модуль с несовместимыми контактами.
3. Подключить HDMI-монитор. **Убавить громкость встроенных динамиков монитора до нуля** (см. примечание о звуке ниже).
4. Подключить наушники к штатному звуковому выходу. Для преподавательского и демонстрационного места использовать активные колонки.
5. Подготовить microSD согласно разделу 3 и установить её в слот платы.
6. Подготовить модуль Pico 2 согласно разделу 4.
7. Подключить USB HID-клавиатуру к Pico 2 (при необходимости использовать USB OTG-переходник/HUB).
8. Подключить питание согласно документации платы. Первое включение выполнять после завершения всех соединений.

Примечание: RP2040-PICO-PC имеет HDMI, audio, microSD и USB-OTG по документации изготовителя. Поддержка каждого устройства зависит также от выбранной прошивки.

**Звук через HDMI.** MOS2 выводит звук только в джек платы, но некоторые прошивки передают звук и по HDMI. Если на мониторах оставлена громкость, запуск такой прошивки на нескольких местах сразу даст какофонию на весь класс. Поэтому громкость динамиков мониторов выставляется в ноль при подготовке места и проверяется перед занятием; звук у учащегося — только в наушниках. Выводит ли прошивка звук в HDMI, указано в [`../COMPATIBILITY.md`](../COMPATIBILITY.md).
 

## 3. Подготовка SD-карты

1. Сохранить нужные данные с карты: форматирование удалит существующее содержимое.
2. Создать раздел с файловой системой **FAT32**. Для использования в учебном классе не полагаться на заводское форматирование карты без проверки типа файловой системы.
3. Скопировать **содержимое** каталога [`sdcard/`](sdcard/) этого репозитория в корень карты. На карте появятся:
   - `/mos2` — MOS2 v2.3.2 с приложениями и `config.sys`. Отдельно скачивать и распаковывать `mos2.zip` не нужно: файлы приложений побайтово совпадают с upstream-комплектом, отличия перечислены в [`MANIFEST.md`](MANIFEST.md).
   - `/test` — файлы для приёмки рабочего места (раздел 5).
4. Прошивки добавлять только совместимые именно с **PCp2 / Olimex PICO-PC + Pico 2**. Не смешивать без проверки бинарники для RP2040, RP2350 и других распиновок. MOS2 и pico-launcher запускают файлы `.uf2` и `.PCp2` (расширение `.PCp2` чувствительно к регистру); прошивки учебного комплекта рекомендуется называть с расширением `.PCp2`, чтобы по имени было видно, для какой платы они собраны.
5. Учебные программы, данные и игры размещать в отдельных каталогах. Состав учебного комплекта и статус проверки прошивок — в [`../COMPATIBILITY.md`](../COMPATIBILITY.md).
6. Целостность эталонного комплекта перед изготовлением копий проверяется по [`SHA256SUMS`](SHA256SUMS) (см. `MANIFEST.md`, раздел 3).

## 4. Установка менеджера прошивок

На Pico 2 устанавливается один из двух менеджеров:

- **pico-launcher — основной вариант** для начального уровня. Файловый браузер SD-карты со справкой (F1), просмотром (F3) и простым редактором (F4) текстовых файлов; запускает прошивки учебного комплекта. Копия: `hardware/olimex-pico-pc/pico-launcher/`. Приёмка — раздел 5.1.
- **murmulator-os2 (MOS2) — расширенный вариант** для занятий с командной строкой, файловой системой и BASIC. Копия: `hardware/olimex-pico-pc/murmulator-os2/`. Приёмка — раздел 5.2.

Версии, исходники и контрольные суммы обоих файлов — в [`MANIFEST.md`](MANIFEST.md).

Для первоначальной установки подходящего UF2 на Pico 2 используется штатный режим BOOTSEL:

1. При отключённом USB удерживать кнопку BOOTSEL.
2. Подключить Pico 2 по USB к компьютеру.
3. Отпустить BOOTSEL после появления USB-накопителя загрузчика.
4. Скопировать на появившийся накопитель соответствующий UF2-файл.

На модулях с отдельной кнопкой RESET повторное подключение USB для входа в BOOTSEL обычно не требуется: удерживая BOOTSEL, кратко нажать RESET, затем отпустить BOOTSEL.
 
В `pico-launcher` и `murmulator-os2` удержание **F11** при включении или перезагрузке предотвращает автоматический запуск выбранной ранее прошивки и открывает файловый менеджер, в котором можно выбрать целевую прошивку — например, игру или эмулятор.


## 5. Приёмка рабочего места

Приёмка проводится для того менеджера, который установлен на место: 5.1 — pico-launcher (основной вариант), 5.2 — MOS2. Общие предусловия: карта подготовлена по разделу 3, менеджер установлен по разделу 4, на время проверки звука наушники не надеты плотно — сначала убедиться, что громкость умеренная.

### 5.1. Рабочее место с pico-launcher

| № | Проверка | Действия | Ожидаемый результат |
|---:|---|---|---|
| 1 | Загрузка | Включить питание; если ранее была выбрана прошивка — удерживать **F11** | Браузер файлов SD-карты, видны каталоги `/mos2` и `/test`, сообщения об ошибке SD нет |
| 2 | Видео | Осмотреть экран | Изображение устойчивое, без срывов и мерцания, текст не обрезан по краям |
| 3 | Навигация | Стрелки, PgUp/PgDn, Home/End; Enter на каталоге `/test` | Выделение перемещается; каталог открывается |
| 4 | Справка | **F1**, затем Esc | Открывается и закрывается окно справки |
| 5 | Просмотр | На `/test/edit.txt` — **F3**, стрелки, затем **F10** | Текст файла виден и прокручивается; F10 возвращает в браузер |
| 6 | Редактор, клавиатура и запись на SD | На `/test/edit.txt` — **F4**; набрать буквы, цифры, цифры на NumPad (с NumLock), Enter, Backspace; Ins; **F2**; Esc; затем снова F3 | Все набранные символы появляются; Ins переключает INS/OVR; после F2 и выхода в просмотре видны сохранённые изменения |
| 7 | Удаление с отменой | На `/test/edit.txt` — **F8**, затем Esc | Появляется запрос подтверждения; после Esc файл на месте |
| 8 | Запуск прошивки | Enter на прошивке из учебного комплекта; затем перезагрузка с удержанием **F11** | Прошивка запускается; после перезагрузки с F11 — снова браузер. До утверждения учебного комплекта пункт не выполняется |
| 9 | Звук | Запустить прошивку учебного комплекта с подтверждённым звуком (см. `COMPATIBILITY.md`) | Звук в наушниках. Сам launcher звук не выводит. До утверждения учебного комплекта пункт не выполняется |

Launcher не использует F5–F7, F9 и F12. F5–F7 проверяются в `mc` при приёмке MOS2 (5.2), остальные — в прошивках, которые их задействуют.

### 5.2. Рабочее место с MOS2

Команды вводятся в консоли MOS2: в `mc` консоль открывается и скрывается по **Ctrl+O**.

| № | Проверка | Действия | Ожидаемый результат |
|---:|---|---|---|
| 1 | Загрузка | Включить питание | Через несколько секунд на мониторе `mc` (Murmulator Commander), сообщений об ошибке SD нет |
| 2 | Процессор и память | `cpu`, затем `mem` | Частота 252 МГц; сведения о памяти выводятся без ошибок |
| 3 | Видео | `mode 0`, `mode 1`, `mode 2`, затем `gmode 2`, затем снова `mode 1` | В каждом режиме изображение устойчивое, без срывов и мерцания, монитор не пишет «нет сигнала». `gmode 2` выводит цветную тестовую таблицу («матрац») и сообщает графическое разрешение драйвера — записать его |
| 4 | Клавиатура | `basic /test/kbdtest.bas`, нажимать клавиши по одной; выход — Ctrl+C | Буквы и цифры выводят свой код и символ; Enter, Esc и NumPad (с включённым NumLock) выводят код. Ctrl+Shift переключает раскладку. F-клавиши BASIC не получает — они проверяются в п. 4а |
| 4а | F-клавиши | В `mc` на файле `/test/edit.txt`: **F1**, **F3**, **F4** — каждое окно закрыть Esc; **F5**, **F6**, **F7**, **F8** — в каждом запросе отменить Esc | Каждая клавиша открывает своё окно или запрос; после отмены файлы и каталоги без изменений. F2, F9, F11, F12 в `mc` не задействованы; F11 проверяется в п. 9 |
| 5 | SD: чтение и запись | `ls /`, `cp /mos2/config.sys /tmp/t.txt`, `type /tmp/t.txt`, `rm /tmp/t.txt` | Каталоги `/mos2` и `/test` видны; копия создаётся, выводится содержимое `config.sys`, файл удаляется |
| 6 | Звук, моно | `wav /test/snd_mono.wav` | Выводятся параметры файла (8000 Hz, 1 канал); три сигнала с повышением тона, в обоих ушах, без треска. После окончания воспроизведения MOS2 зависает (известная проблема, см. ниже) — сбросить плату |
| 7 | Звук, каналы | `wav /test/snd_lr.wav` | Низкий сигнал только слева, средний только справа, высокий в обоих. Если каналы перепутаны — записать в примечание к `COMPATIBILITY.md`. После воспроизведения — сброс, как в п. 6 |
| 8 | Переключение прошивок | В `mc` выбрать прошивку из учебного комплекта, Enter; затем перезагрузка с удержанием **F11** | Прошивка запускается; после перезагрузки с F11 — снова MOS2. До утверждения учебного комплекта пункт не выполняется |
| 9 | Перезагрузка | Ctrl+Alt+Del | MOS2 загружается заново, как в п. 1 |

Известные проблемы MOS2 2.3.2 на PCp2:

- `wav` зависает после окончания воспроизведения (проверено без PSRAM). Звук при этом воспроизводится полностью, поэтому для приёмки достаточно сбросить плату после каждого файла.
- `blimp` для проверки звука не используется: в этой сборке он выводит сигнал на GP26, который не подключён к звуковому джеку.

### 5.3. Отбор модуля Pico 2 по разгону

**Статус:** черновик. Длительность прогонов и итоговый порог по напряжению требуют подтверждения.

Большинство эмуляторов комплекта работают с разгоном ядра RP2350 и повышенным напряжением (см. колонку «Частота / напряжение» в [`../COMPATIBILITY.md`](../COMPATIBILITY.md)). Экземпляры RP2350 отличаются по разгонному потенциалу, поэтому каждый модуль Pico 2 проверяется до установки на рабочее место. Проверка выполняется на собранном рабочем месте с SD-картой из раздела 3.

| № | Прошивка | Режим | Действия | Критерий |
|---:|---|---|---|---|
| 1 | PICO-BK | 720×576, 270 МГц / 1.3 В | Запустить `/emu/PCp2-bk-…uf2` | Устойчивое изображение, звук в наушниках |
| 2 | PICO-BK | 800×600, 400 МГц / 1.5 В | Home → пункт HDMI → пробел; запустить игру со встроенной дискеты (Tab, стрелки, Enter), играть 30 минут | Нет зависаний, сбросов, артефактов изображения и звука |
| 3 | PICO-BK | 1024×768, 512 МГц / 1.6 В | Home → HDMI → пробел; повторить п. 2 | То же. Если монитор не показывает 1024×768, пункт пропускается — проверку частоты выполняет п. 4 |
| 4 | murm386 | 504 МГц / 1.6 В | Запустить `/emu/PCp2-386-…uf2`, дождаться Volkov Commander; запустить `\FREEDOS\SI.EXE`; оставить работать 30 минут | FreeDOS загружается, SI выводит индекс производительности, система не зависает |

После проверки вернуть в PICO-BK видеорежим 720×576 (Home → HDMI), чтобы карта и модуль были в исходном состоянии.

Модуль относится к классу по максимальному пройденному режиму:

| Класс | Пройдено | Пригоден для |
|---|---|---|
| A | п. 1–4 | всех прошивок комплекта, включая murm386 |
| B | п. 1–2 | прошивок до 400 МГц / 1.5 В: launcher, MOS2, PICO-BK, pico-nes (378 МГц — проверить отдельно) |
| C | п. 1 | launcher, MOS2 и прошивок до 270 МГц |

На места учащихся устанавливаются модули класса A. Модули классов B и C маркируются и используются как запасные для лёгких задач или на месте преподавателя.

Работа с разгоном и напряжением выше штатного выполняется вне гарантированных производителем режимов и может со временем снижать устойчивость чипа. Проверку п. 2–4 повторяют раз в учебную четверть и при появлении необъяснимых зависаний на рабочем месте.

Результат приёмки записывается в [`../COMPATIBILITY.md`](../COMPATIBILITY.md): дата, экземпляр платы, пройденные пункты, замечания; для модулей Pico 2 — класс по разделу 5.3.

**Статус приёмки:** не выполнена до испытаний конкретного комплекта. Документ не утверждает, что произвольные релизные бинарники совместимы друг с другом.

## 6. Тиражирование на весь класс

После успешной приёмки эталонного места зафиксировать версии менеджера и прошивок, состав SD-карты, настройки и результаты тестов. С эталонной SD-карты изготовить копии для остальных мест; проверить запуск и аудио на каждом экземпляре. Не считать проверку одного образца доказательством исправности всей партии оборудования.

Быть готовым к тому, что дети испортят данные на SD-карте, т.е. желательно иметь заранее подготовленные резервные экземпляры, для быстрой замены, без задержки учебного процесса.
