# Общее содержимое SD-карты

Состояние на 2026-10-05. Каталог `sdcard/` в корне репозитория — общая для всех плат часть учебной SD-карты: MOS2 и её приложения, FreeDOS для murm386, игры и учебные программы, файлы для приёмки рабочего места. Здесь описано, что в нём лежит, откуда взято и как проверить целостность. При изменении состава обновляются этот файл и [`SHA256SUMS`](SHA256SUMS).

## 1. Порядок подготовки карты

1. Отформатировать карту в FAT32 с размером кластера 4 КБ — см. инструкцию к своей плате (для Olimex PICO-PC — [`hardware/olimex-pico-pc/README.md`](hardware/olimex-pico-pc/README.md), раздел 3).
2. Скопировать **содержимое** общего каталога [`sdcard/`](sdcard/) в корень карты.
3. Затем скопировать поверх **содержимое** каталога `sdcard/` своей платы — например, [`hardware/olimex-pico-pc/sdcard/`](hardware/olimex-pico-pc/sdcard/) для Olimex PICO-PC. Там лежат прошивки, собранные именно под эту плату (эмуляторы в `/emu`); при совпадении имён файлы платы заменяют общие.

## 4. Программы для murm386 (`/freedos/GAMES`, `/freedos/EDU`)

Подборка рассчитана на производительность murm386 без PSRAM: примерно 2–3 PC XT, то есть уровень Turbo XT или PC AT 8 МГц. Без PSRAM быстрее не получится из-за частого свопа. Уменьшить число промахов кэша помогают режимы EGA128 и VGA128 (дополнительно 128 КБ SRAM) и MCGA (ещё 64 КБ). Программы, которым нужна PSRAM, в комплект не входят — их можно добавить отдельно. На рабочих местах с PSRAM можно запускать сборки murm386 из `/emu/psram` (см. `hardware/olimex-pico-pc/MANIFEST.md`): гостевая память у них целиком в PSRAM, своп не нужен.

Отбор: скорость уровня XT/AT; видео текстовое, CGA, EGA или VGA/MCGA. murm386 поддерживает XMS, поэтому программы, использующие расширенную память, тоже подходят — ограничение задаёт скорость, а не объём памяти. ## 5. Программы и игры для pico-speccy (`/ZX`)

pico-speccy открывает файлы из любого каталога SD-карты через файловый браузер (F5) и понимает почти все форматы Спектрума: `.tap`, `.tzx`, `.z80`, `.sna`, `.trd`, `.scl` и др. Файлы ZX81 (`.p`) открываются клавишей F2; эмулятор сам переключается в режим ZX81+. Подборка лежит в `/ZX`.

Управление: **F1** — меню эмулятора (модель компьютера — Machine → Spectrum: 48K, 128K, +2, +3, ZX81+ и др.); **F5** — открыть файл, Enter — загрузить и запустить; **Shift** — CAPS SHIFT; **Ctrl** — SYMBOL SHIFT; **Esc** — BREAK; **F11** — сброс Спектрума; **F9/F10** — громкость.

Рядом с каждым файлом лежит файл `.TXT` с описанием, авторами и текстом лицензии. Файлы переименованы в короткие имена, содержимое не изменено.

## 12. Диски для «Корвета» (`/korvet`)

Прошивка «Корвета» (порт Emu80, ветка `korvet` репозитория [DnCraptor/emu80v4](https://github.com/DnCraptor/emu80v4)) хранит образы дисков в каталоге `/korvet` и сама создаёт его при первом запуске. ПЗУ «Корвета» встроены в прошивку; без диска «Корвет» стартует во встроенный Бейсик.

Управление: **Alt** — меню эмулятора (диски, настройки), **Alt+A** — вставить образ диска в дисковод A; система загружается с диска A после сброса — **F11**. **Alt+J** — раскладка ЙЦУКЕН, **Alt+Q** — QWERTY. **Ctrl+Alt+Del** — перезагрузка платы. Геймпад NES: Start — меню, крестовина — стрелки, A — пробел, B — Enter.

Это небольшая подборка «на старте»: три диска из коллекций, которыми обмениваются любители «Корвета» (чат [ZX_MURMULATOR](https://t.me/ZX_MURMULATOR/282025/282087), [ещё](https://t.me/ZX_MURMULATOR/282025/282029)). Образы не изменены, только переименованы. Все три диска проверены в настольном Emu80 v4 (ветка `original` того же репозитория): диск загружается; из программ проверены `KLAVIT.TRN`, `LOGIKA`, `FIZIKA`, `KLAD`, `XONIX`, `TENNIS` и `MW`, остальные — по каталогу диска.

| Файл | Что на диске | Как запустить |
|---|---|---|
| `SCHOOL.KDI` | МикроДОС 2.6 (НИИСЧЕТМАШ, 1990) и школьные программы на Бейсике 1988–1990 годов: клавиатурный тренажёр «для ЭВМ типа КОРВЕТ» (`KLAVIT.TRN`), «Основы информатики и вычислительной техники, 10 класс» — логические элементы И, ИЛИ (`LOGIKA`), уроки программирования на Бейсике (`UROK1`–`UROK10`), «Движение тела под действием силы тяжести» (`FIZIKA`, Черновцы, 1988), таблица Менделеева (`TABMEN`), «Рисуют школьники» (`RISUNOK`), «Мозаика» (`MOZAIKA`), игры «Реверси» (`REWERSI`) и «Стрельба из орудия» (`ORUDIE`) | после загрузки (`A>`) набрать `BASIC`, затем, например, `RUN"KLAVIT.TRN"` или `RUN"LOGIKA"` |
| `GAMES.KDI` | CP/M 2.2 («ПК Контур», 1990) и игры: «Клад» (Lode Runner, `KLAD`, `KLAD1`–`KLAD3`), «Ксоникс» (`XONIX`, МГУ, 1988), «Сокобан» (`SOKOBAN`), «Теннис» (`TENNIS`), «Шахматы» (`CHESS`), «Карате» (`KARATE`), «Ралли» (`RALLY`), «Гонки» (`GONKI`), `JUMPER`, `ARK`, `ARC` и другие | после загрузки (`A>`): `DIR` — список, имя игры — запуск, например `KLAD` |
| `MUSIC.KDI` | CP/M 2.2 и музыкальный редактор Music World (Woodman, 1990) с мелодиями: «Калинка», «Вологда», «Соловей», «Менуэт» и др. | после загрузки набрать `MW` |

Программы для «Корвета» 1980-х — 1990-х годов распространяются без открытой лицензии; образы будут удалены из репозитория при претензии правообладателя.

## 14. Программы для pico-pce (`/PCE`)

pico-pce (эмулятор PC Engine, ядро pce-go) показывает картриджи из каталога `/PCE`, там же хранит настройки (`pico-pce.cfg`) и сохранения. Выбранный картридж записывается во флеш-память платы, поэтому запуск нового картриджа идёт чуть дольше обычного.

Управление: стрелки (или WASD) — крестовина, **Z** — кнопка I, **X** — кнопка II, **Enter** — RUN, **Esc** или **Backspace** — SELECT; **Enter+Esc** — меню эмулятора (сохранения, частота, возврат к выбору картриджа); **Ctrl+F1–F8** — сохранить игру в ячейку, **Alt+F1–F8** — загрузить; **Ctrl+Alt+Del** — перезагрузка платы. Геймпад NES: A — I, B — II, Start — RUN, Select — SELECT, Start+Select — меню.

Картриджи написаны на C для этого репозитория (исходники и сборка — [`tools/pce`](tools/pce/README.md), условия — [`LICENSE`](LICENSE)). Тексты на экране — латиницей.

| Файл | Программа |
|---|---|
| `hello.pce` | текст и цвета, часы в секундах, показывает нажатые кнопки; I и II — звук |
| `sprite.pce` | стрелки — водить робота, мяч летает сам; коснуться мяча — очко, I — другая палитра робота |

## 15. Программы для pico-genesisPlus (`/MD`)

pico-genesisPlus (эмулятор Sega Mega Drive / Genesis, ядро gwenesis) показывает файлы `.md` и `.bin` из любого каталога карты, начиная с корня. Свои файлы он хранит в корне карты: настройки (`settings_*.dat`), список недавних игр (`recent_*.txt`), запись о картридже во флеш-памяти (`flashedrom.dat`), каталоги `/SAVES` (сохранения картриджей) и `/SAVESTATES` (снимки игры). Выбранный картридж записывается во флеш-память платы, плата при этом перезагружается; без PSRAM помещаются картриджи примерно до 2,4 МБ.

Клавиши у pico-genesisPlus свои, не такие, как у остальных эмуляторов комплекта, и в меню они не те, что в игре.

В списке файлов и в меню:

| Клавиша | Действие |
|---|---|
| ↑ ↓ ← → | выбор |
| **X** | открыть каталог, запустить игру, подтвердить |
| **Z** | назад: каталог выше, выход из меню |
| **A** | настройки |
| **C** | недавние игры |

В игре — геймпад Mega Drive на клавиатуре:

| Клавиша | Кнопка Mega Drive |
|---|---|
| ↑ ↓ ← → | крестовина |
| **Z**, **X**, **C** | A, B, C |
| **Q**, **W**, **E** | X, Y, Z (шестикнопочный геймпад) |
| **S** | START |
| **A** | не кнопка игры, а клавиша для сочетаний: |
| **A+S** | меню: снимки игры (сохранить, загрузить), сброс игры, выход к списку файлов |
| **A+↑** | режим экрана |
| **S+Z** | показать или скрыть частоту кадров |

Геймпад NES на UEXT, пока USB-клавиатура не подключена, — первый игрок: B — B, A — C, SELECT — A, START — START, SELECT+START — меню. У части клонов «Денди» A и B меняются местами, а C достаётся SELECT. Когда подключена USB-клавиатура, она — первый игрок, а геймпад NES — второй.

Картриджи написаны на C для этого репозитория (исходники и сборка — [`tools/md`](tools/md/README.md), условия — [`LICENSE`](LICENSE)); это те же программы, что для PC Engine в разделе 14. Тексты на экране — латиницей.

| Файл | Программа |
|---|---|
| `hello.bin` | текст и цвета, часы в секундах, показывает нажатые кнопки; A, B и C — звук |
| `sprite.bin` | стрелки — водить робота, мяч летает сам; коснуться мяча — очко, A — другая палитра робота |

Картриджи написаны на C для этого репозитория (исходники и сборка — [`tools/lynx`](tools/lynx/README.md), условия — [`LICENSE`](LICENSE)); это те же программы, что в разделах 14–16. Тексты на экране — латиницей.

## 18. Проверка целостности

Из корня репозитория:

```sh
sha256sum -c SHA256SUMS          # Linux, Git Bash в Windows
shasum -a 256 -c SHA256SUMS      # macOS
```

Файлы `*.md` в `SHA256SUMS` не включены: git может менять в них концы строк при checkout. Файлы под `sdcard/` git хранит байт в байт (`.gitattributes`), поэтому контрольные суммы совпадают в любой ОС.
